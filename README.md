## A little about me

I'm a student who learns best by building real projects, running into problems, and figuring out what's actually going on. Lately, I've been exploring how AI can be turned into useful tools instead of just a cool demo.

- **Interested in:** AI/ML, computer vision, automation, and full-stack development
- **Building:** projects that mix models, data, and practical interfaces
- **Usually doing:** prototyping, debugging, or pushing an idea further than the first version
